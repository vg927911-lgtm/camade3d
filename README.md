# Camadê 3D

Catálogo responsivo de peças para impressão 3D, feito com HTML, CSS, JavaScript e Vite.

## Funcionalidades
- Catálogo de peças com busca por nome, categoria, descrição e material.
- Filtros por categoria.
- Painel administrativo para adicionar, editar e excluir peças.
- Campos para preço, material, descrição e URL da imagem.
- Persistência local usando localStorage.

## Executar localmente
```bash
npm install
npm run dev
```

## Observação
Esta é uma primeira versão de interface. Os cadastros ficam no navegador em que foram feitos. Ainda não há autenticação, banco de dados, upload de imagens ou publicação.
